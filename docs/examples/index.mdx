# Examples

Each example carries one problem the whole way along the derivation used throughout this
reference. Nothing is elided: the structure is stated, the concept is written, the algorithm is
written against the concept, the cost is computed, the hardware mapping is made, and the
measurement protocol is given.

## Reading them

The examples are written to be read in order, since each uses the previous: the inner product is
a kernel of conjugate gradient, and the blocking analysis of matrix multiplication is the model
for every dense kernel.

The code in each is complete and compiles as shown against C++20 unless the entry says otherwise.
Where a later revision offers a better formulation, both are given.
